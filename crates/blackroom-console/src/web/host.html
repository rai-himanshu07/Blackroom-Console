        Network
        
      
      
        
      
      
        The certificate files and Internet mode are chosen under "Access from outside". Network changes need a restart. If another program already uses a port, saving is refused and says which one: pick a free port (for example 8081 for http, 8444 for https). A router forward must then use the new https port; "Currently running" lists the ports to forward after the restart. This page's own port (8090) is fixed.
