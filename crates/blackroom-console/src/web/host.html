Access from outside

Nothing is opened to the internet. For Tailscale, make the files with sudo tailscale cert (the commands are in docs/ops/internet-access.md) and renew them about every 60 days. Without files the console keeps its own certificate and browsers warn once.

Strangers' scanners can reach this. Saving is refused unless login goes through the login authority, the plain-http address is loopback only, https is on and the certificate checks out. Forward the https port and the media ports on the router: blackroom internet prints the exact list.

Settings for the two modes you are not using are remembered, so switching back is one step. A change needs a restart, which ends a running session.

What the running console checked

    Local checks only; nothing here is tested from the internet. A phone on mobile data is the real test.

    Network

    The certificate files and Internet mode are chosen under "Access from outside". Network changes need a restart. A wrong address stops the console from starting: check them before restarting.

    How clients sign in

    The first method needs the login authority: use "Set up the login authority" under Credentials below once, then choose it here, Save and restart the console.

    Authenticator app
